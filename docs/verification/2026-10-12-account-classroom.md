# 계정·학급 실행 검증

2026-10-12, 격리된 관리 작업트리와 전용 Compose 프로젝트에서 실행했습니다. 계정·학급 첫 단계입니다.

| 검증 | 결과 |
| --- | --- |
| Java 21 / 실제 PostgreSQL 17 통합·단위 테스트 | 38개 통과, 실패·건너뜀 없음 |
| React UI 테스트 | 23개 통과 |
| TypeScript 빌드 / Vite / ESLint | 통과 |
| Docker Compose 구성·이미지·서비스 준비 | 통과 |
| Chromium 실제 브라우저 | 12개 통과 |
| 320/390/768/1440px 가입·로그인 | 가로 넘침 없음, 주요 버튼 44px 이상 |
| 서버 재시작 후 학생 | UUID·이름·별명·학급 소속 동일 |
| 서버 재시작 후 교사 명단 | 실제 학생 이름·번호 유지 |
| 초기 관리자 환경 변수 제거 후 재생성 | 기존 관리자 로그인 유지 |

브라우저는 실제 발급·첫 비밀번호 변경·학급 생성·학생 가입·별도 로그인·새로고침·명단·역할 전환을 수행했습니다. 각 흐름은 고유 학급을 사용하며 DB 직접 주입을 하지 않았습니다. DB 볼륨을 삭제하지 않았습니다.

초기 실제 브라우저 검사에서 빠른 로그인 제출이 CSRF 오류를 일으켰습니다. 익명 Me 조회의 요청 저장 기능이 별도 세션을 생성하는 것을 실패 테스트로 재현한 뒤 NullRequestCache로 수정했고, 회귀 테스트와 전체 검사로 검증했습니다.

비밀번호 입력 화면의 trace·영상·자동 스크린샷은 저장하지 않습니다. 초기 비밀번호는 발급 직후 컴포넌트 상태에서만 표시하며 목록·저장소·조회 캐시에 보관하지 않습니다.

운영 학교 서버·도메인·TLS 배포와 학습 문항·30회 진행·타이머·보상·지도는 이 검증 범위에 포함하지 않았습니다.

## 최종 코드 리뷰 반영

전체 구현 브랜치에 대해 별도 컨텍스트의 읽기 전용 리뷰를 수행했습니다. Critical과 별도 Minor 지적은 없었고, Important 세 건을 한 번의 수정 단계에서 처리했습니다. 각 사례는 실패를 확인한 뒤 수정했으며, 수정 후 전체 73개 테스트와 빌드·린트·컨테이너·실제 브라우저 검증을 통과했습니다. 수정 뒤 별도 재리뷰는 수행하지 않았습니다.

| 지적 | 수정·회귀 검증 |
| --- | --- |
| 저장 가능한 비밀번호가 로그인에서 거부됨 | 로그인은 비밀번호 원문을 받도록 통일. 공백 8자의 가입→로그인, 학생·직원 변경→재로그인 검증 |
| 초기 비밀번호를 그대로 유지하면서 강제 변경 표시만 해제됨 | 강제 변경 계정의 동일 비밀번호 제출 거절. 변경 필요 상태·버전·업무 차단 유지 검증 |
| CSRF 재조회 실패가 완료된 로그인·변경을 실패로 표시함 | 인증 성공과 토큰 복구 분리, 이전 토큰 폐기. 성공 화면 유지·변경 한 번만 수행·복구 전 POST 차단·새 토큰 사용 검증 |

## 실행 중 확정한 사항

| 결정·이유 | 비용 또는 후속 작업 |
| --- | --- |
| Windows IPC·Docker 접근 제약으로 승인된 호스트 실행 권한 사용 | 실행 환경 설정에만 영향 |
| 원본 checkout 대신 관리 작업트리에서 격리 구현 | 원본 checkout에 반영하는 통합 단계가 별도로 필요 |
| HTTP 모의 테스트 도우미는 해당 테스트에만 명시적으로 연결 | 실제 포트 테스트에는 MockMvc가 없어 테스트 구성 분리 필요 |
| 입력 정규화·길이·제어 문자 검사를 공통화 | 허용할 이름 문자가 달라지면 규칙 조정 필요 |
| 린터 호환 안정판 TypeScript 6.0.3과 Node 24 타입 고정 | 향후 도구 호환성 업데이트 필요 |
| JSON API의 요청 저장을 꺼 익명 Me/CSRF 세션 경합 제거 | HTML 로그인 리다이렉트가 추가되면 별도 반환 경로 설계 필요 |
| 공개 TLS·외부 트래픽 운영 방어는 배포 단계로 유지 | 외부 공개 전에 해당 배포 검증 필요 |
| 분산 세션·다중 서버 부트스트랩은 현재 단일 백엔드 범위에서 제외 | 수평 확장 시 별도 세션·초기화 조정 필요 |
| 복구·학교 추가·반 이동·학기 초기화는 승인된 제외 범위 유지 | 해당 운영 기능은 후속 개발 필요, 현재 복구 기능 없음 |
| 문항·30회 진행·타이머·보상·지도·개인 별표는 후속 모듈로 유지 | 전체 학습 게임은 추가 구현 필요 |

보류한 경미한 리뷰 지적은 없습니다.
