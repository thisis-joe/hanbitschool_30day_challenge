# 경험치·아이템 획득 연출 및 장비 착용 개선

- 날짜: 2026-10-19 (Asia/Seoul)
- 브랜치: `feat/game-rewards-equipment-polish`
- 작업 시작점: `01aa3d6` (`docs/current-screenshot-guide`의 당시 HEAD)
- 기존 미추적 `.DS_Store`, `.pnpm-store/`는 수정하거나 커밋하지 않았다.

## 작업 단위

1. `3a54a91` — 경험치·아이템 획득 연출. 별 입자 18개, 빛의 파동, 방사형 광선, 떠오르는 XP 숫자, 아이템 등장과 보물상자 움직임을 추가했다. 경험치 패널은 정답 판정 바로 아래에 배치했다. 각 연출은 최대 2.4초에 끝나고 조작을 가로막지 않는다.
2. `9f51795` — 장비 착용 개선. 모자 5종, 가방 3종, 조끼·반바지·신발 각 5종을 세밀한 윤곽과 음영으로 다시 그렸다. 9명별 손 기준점, 가방 손잡이/지팡이 축 위치, 손의 앞쪽 겹침, 모자와 왕관의 비율, 신발 밑의 맨발 노출을 수정했다. 인벤토리와 착용 장면은 같은 장비 아트를 사용한다.

## 획득 처리와 접근성

- 서버가 확인한 답변 ID, 아이템 ID와 획득 시각을 사용한다. XP 0은 획득 효과를 표시하지 않는다.
- 같은 계정·콘텐츠의 동일 획득은 QueryClient가 유지되는 세션 안에서 한 번만 재생한다. 일반 보유 목록의 첫 조회는 신규 획득으로 간주하지 않는다.
- 계정 변경/로그아웃 시 기존 cosmetic 캐시 정리와 취소 epoch를 따른다. 브라우저 전체 새로고침을 넘어 영구 저장하는 기능은 추가하지 않았다.
- `prefers-reduced-motion`에서는 획득 내용을 정적으로 표시한다. 입자와 광선은 접근성 트리에서 숨기고 `pointer-events: none`을 사용한다.
- 획득 배지 공간은 연출 후에도 유지해 착용 버튼의 위치가 갑자기 바뀌지 않는다.

## 검증

Node 24.19.0 / pnpm 11.25.0에서 다음을 실행했다.

| 검증 | 결과 |
| --- | --- |
| `pnpm test` | 최종 실행 37개 파일, 290개 테스트 통과 |
| `pnpm build` | TypeScript 및 Vite 프로덕션 빌드 통과 |
| `pnpm lint` | 통과 |
| `git diff --check` | 통과 |
| Chromium `equipment-renderer.spec.ts` | 9명 × 8조합 = 72개 캔버스 렌더링, 피부가 손 장비 앞에 유지됨, 가방이 손 아래에 존재함을 실제 픽셀로 확인 |
| Chromium `game-celebrations.spec.ts` | 1280px·390px의 답변→XP→완료→아이템→착용, 키보드 Enter 착용, 가로 넘침 없음, 동일 선물 재방문 중복 재생 없음, 모션 감소: 3개 테스트 통과 |

브라우저 검증은 로컬 Vite와 합성 API 응답으로 실제 React 페이지를 실행했다. 운영 서버·실제 학생 계정·백엔드 지급 로직 검증을 의미하지 않는다. 신규 브라우저 테스트 4개에서 페이지 JavaScript 예외는 없었다.

빌드와 함께 실행한 첫 브라우저 검수에서 Vite 페이지가 다시 로드되어 캔버스 검사 1회가 중단됐다. 빌드 종료 후 재실행 및 최종 4개 테스트가 통과했다. 초기 픽셀 비교에서 원본 피부의 알파 252–254를 확인하여, 손잡이 위 source-over 합성에 맞게 불투명도와 RGB 오차 3 이하를 검사한다. 9명 모두 이 조건을 만족한다.

최종 회귀 검사 도중 기존 `returningAccountCanUsenextAfterACanceledResultStatusRead` 테스트가 한 차례 연결 오류 화면을 반환했다. 해당 파일 단독 31개와 전체 290개를 코드 변경 없이 재실행해 통과했다. 해당 테스트는 선물이 없는 계정 전환 경로를 검사한다. 일시 실패의 원인은 확정하지 않았으며, 테스트 완화나 계정 전환 코드 변경은 하지 않았다.

## 검토 범위

커밋 전 전체 변경 파일과 신규 파일을 직접 검토했다. 지급 수치·API 변경 없이 연출이 작동하는지, 사용자 입력을 SVG에 삽입하지 않는지, 비동기 아바타 렌더링의 취소/최신 프레임 보장이 유지되는지 확인했다. 별도의 독립 리뷰 에이전트는 사용하지 않았다. 과거 다운로드 파일과 픽셀 일치를 요구하던 장비 검사는 이번 디자인 요구에 맞춰 저장소 자체의 실제 착용 검수로 교체했다.
