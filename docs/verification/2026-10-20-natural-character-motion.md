## 보고된 문제

PR #9 배포 후 검수에서 다음 문제가 확인됐다.

1. 팔이 움직일 때 몸에서 분리되고, 팔 모양이 부자연스럽다.
2. 이동과 점프가 느리고, 다리가 전혀 움직이지 않아 점프가 부자연스럽다.
3. 표정이 얼굴 위치에서 벗어난다.
4. 안경이 표정 아래에 그려진다.
5. 걷기·점프·풀이 죽기에서 머리카락이 움직이지 않는다.

## 원인과 수정

이전 리그는 원본 그림에서 잘라낸 팔 조각을 어깨 한 점으로만 회전시키고, 다리는 회전 없이 몸통에 붙어 있었다. 표정은 눈·입 위치를 옷 기준 앵커에서 추정해 사각형으로 덮어 그렸고, 안경은 몸통 레이어에 함께 구워져 표정 아래에 남았다.

- `motion/anatomy.ts`(신규): 원본 128×176 그림에서 캐릭터별 어깨·팔꿈치·손바닥·반대쪽 어깨·눈·입 좌표를 측정해 기록했다. 발 목표에 맞춰 무릎을 푸는 2관절 역기구학(`knee`)과 회전 보조(`rotated`)를 제공한다.
- `motion/rig.ts`: 팔·다리를 어깨-팔꿈치-손, 엉덩이-무릎-발목 세 관절 체인으로 분리하고, 1픽셀 가로 띠를 겹쳐 그리는 메시 변형으로 관절을 따라 휘게 했다. 관절 아래에는 원본 피부색 코어를 먼저 그려 굽힐 때 투명한 틈이 생기지 않는다. 손이 반바지와 겹치는 높이에서 허벅지가 팔로 잘려 나가던 경계를 분리했다. 머리는 몸통에서 분리해 목 기준으로 기울이고, 긴 머리(땋은 머리·포니테일·옆머리)는 뒤쪽 레이어로 분리해 끝부분이 지연되어 흔들린다. 표정은 머리 텍스처에 눈·입 모양 마스크로 구워 넣어 얼굴을 벗어날 수 없고, 안경·모자는 머리 위에 마지막으로 그린다. 손 장비는 손 관절을 따른다.
- `motion/poses.ts`: 걷기는 240ms 보폭 주기로 발을 번갈아 들고 디디며 출발·도착에서 완화된다. 정답은 무릎 굽힘 → 포물선 점프 → 착지 압축 → 두 번째 낮은 점프 → 양팔 든 자세의 연속 곡선이며, 구간 경계에서 좌표가 튀지 않는다. 오답은 허리를 숙이고 팔을 늘어뜨리며 머리카락이 한 번 흔들린다. 이동 480ms, 정답 반응 900ms, 오답 반응 360ms를 `MOTION_MS`로 공유한다.
- `AnswerGameScene.tsx`·`answer-scene.css`: 이동 시간을 750ms에서 `MOTION_MS.walk`(480ms)로 줄이고 CSS 전환도 같은 변수로 맞췄다. 보상 연출은 여전히 도착과 반응이 끝난 뒤 시작한다.
- `avatarRenderer.ts`: 모자 배치를 `avatarHatPlacement`로 공유해 정지 렌더러와 관절 리그가 같은 위치에 모자를 그린다.

## 브라우저 검수 — 통과

개발 서버 `pnpm --dir frontend dev --port 8103`의 `/e2e/fixtures/answer-motion.html`에서 실제 제품 컴포넌트와 원본 아트를 사용했다.

- 9명 × 기본·1번·5번 장비 × 6개 포즈 = 162개 캔버스 렌더 완료.
- 걷기·점프·숙이기 전 프레임에서 팔다리가 몸에 붙어 있다. 걷기는 무릎을 굽혀 발을 들고, 점프는 무릎을 굽힌 뒤 뛰어 착지 시 다시 굽힌다.
- 웃는·슬픈 표정이 각 캐릭터의 눈·입 위치 안에 그려지고, 1번 장비의 안경이 표정 위에 보인다.
- 포니테일·땋은 머리·긴 머리가 걷기와 점프에서 흔들리고, 숙일 때 머리를 따라 내려온다.
- O 목적지와 캐릭터 중심 차이 0px, pageerror 0.

[실제 컴포넌트 동작 녹화](recordings/2026-10-20-natural-character-motion.mp4)는 11.16초, H.264 736×536, 765,483바이트다. 하루의 O 정답(걷기 → 두 번 점프) → 보라의 X 오답(걷기 → 숙이기, 머리카락) → 나루 1번 장비의 X 응답 대기 → 서버 정답(안경이 표정 위) 순서다. 계정이나 운영 데이터는 사용하지 않았다.
