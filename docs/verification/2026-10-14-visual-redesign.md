## 실행 중 판단과 되돌릴 때의 비용

1. 이미 승인된 한정된 디자인은 내부 실행 분해로 기록하고 재승인 절차를 추가하지 않음. 틀렸을 때 비용: 작업 분해·문서 조정.
2. 작업별 관련 테스트, 통합 후 전체 프런트엔드 검증을 사용. 틀렸을 때 비용: 작업 간 문제를 통합 단계에서 발견.
3. 원본 옷장처럼 여섯 카테고리 선택으로 인벤토리를 표시. 틀렸을 때 비용: 장비 데이터 변경 없이 이전 긴 목록으로 복원.
4. 학습 경로에서 돌아올 때 실제 새 해금만 표현하도록 기존 계정별 Query Cache에 최소한의 시각 효과 관찰 이력을 저장. 최초 관찰은 조용하며 인증 캐시 교체가 이력을 지움. 틀렸을 때 비용: 시각 효과 이력 조정; 해금·소유권 권한에는 영향 없음.
5. 결과 화면에 남아 있던 보상 카드의 별도 배경·테두리 색 덮어쓰기를 제거하도록 좁은 스타일 범위를 추가. 승인된 굵은 보물상자 프레임을 일관되게 표시하기 위한 조정. 틀렸을 때 비용: 결과 화면의 색상만 복원.
6. 통합 검증에서 재현한 기존 완료 이동 경쟁 상태를 막기 위해 완료 링크에 기존 blocked 상태 보호와 결정적 회귀 검사를 추가. 명령 정리·XP·해금·저장·인증 규칙은 유지. 틀렸을 때 비용: 기존 확인이 끝날 때까지 완료 이동이 더 기다릴 수 있어 UI 보호 조건 조정 필요.
7. 저장 지속성 E2E의 예전 무한 호흡 애니메이션 기대값을 승인된 유한 등장 효과로 갱신하고 반복 횟수·모션 줄이기 검사는 유지. 학습·저장 검사는 약화하지 않음. 틀렸을 때 비용: 장식 효과 테스트의 기대값 재조정; 서버·데이터 영향 없음.
8. 이 작업의 임시 실행 폴더는 영구 삭제 대신 로컬 검증 아카이브로 이동해 화면 증거·리뷰를 복구 가능하게 보존. 다른 작업 폴더는 변경하지 않음. 틀렸을 때 비용: 정리할 때까지 로컬 디스크 공간 추가 사용.
