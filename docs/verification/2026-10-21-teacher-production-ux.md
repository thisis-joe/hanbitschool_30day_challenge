- 운영 주소: https://hanbit.thisis-joe.com

- 기능 브랜치: `fix/teacher-production-ux`.
- 최종 제품 소스: `690caf0c810d75272c9bc4ab72b0510c3532ac48`.

## 실제 운영 브라우저 검증

사용자가 로그인한 Chrome 교직원 세션에서 기존 검증용 학급과 합성 학생 1명을 사용했다. API 대체나 DOM 주입 없이 운영 UI를 조작했다. 교사 화면 검증 중 학급·학생·학습 기록을 생성하거나 변경하지 않았다.

브라우저 확장 프로그램의 content-script 오류는 관찰되었으며 사이트 오류와 구분했다. 초기에 Python urllib의 공개 요청은 403을 받았지만, 실제 브라우저와 curl의 운영 요청은 성공했다. 이를 제품 조회 실패로 집계하지 않았다.

검증 범위의 한계: 모바일은 Chrome 뷰포트 에뮬레이션이며 실물 iOS/Android 검사는 아니다. 제공된 로그인 계정에는 관리자 메뉴가 표시되어, 교사와 관리자가 공유하는 화면·조회 동작을 검증했다. 별도 TEACHER 계정의 권한 차이, 새 학급 생성 저장, 비밀번호 변경, 관리자 계정 발급은 이번 운영 검사 범위에 포함하지 않았다. 합성 학급은 학생 1명이므로 이전/다음 학생 경계의 비활성 상태를 확인했고, 다인 학급 이동은 단위 회귀 테스트로 확인했다.

## 코드·빌드 검증

- Node 24 / pnpm 11.25.0, 격리된 worktree에서 전체 단위 **39개 파일·311개 통과**, build·lint 통과.
- 필터 대기 중 컨트롤 유지·요약 유지 테스트 2개는 수정 전 실패, 수정 후 통과했다.
- 이름 링크와 회차 선택 포커스 회귀는 수정 전 실패, 수정 후 통과했다.
- 마지막 스크롤 동작 변경 후 교사 관련 **4개 파일·26개 테스트**, build·lint 통과. 이후 CSS 보정마다 build·lint 및 영향받는 운영 화면을 재검증했다.
- 기존 계정·학급 전환, 늦은 응답 차단, 권한 없는 화면 접근, 필터·정렬·페이지·모달 회귀 포함.
- 최종 변경 전체를 React 구성·쿼리 범위·키보드 동작·의존성 관점에서 자기 검토했다. 독립 리뷰어 검토는 수행하지 않았다.
- 전체 backend 테스트 및 이전 별도 Playwright E2E 스위트는 재실행하지 않았다. 이번 실제 브라우저 증거는 CUA 운영 세션이다.
