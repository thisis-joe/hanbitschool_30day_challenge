# 답변 선택과 캐릭터 감정 동작 검증

- 기능 브랜치: `feat/answer-character-motion`
- 기준 커밋: `76406ba`
- 구현 커밋: `d74bcee` (관절·포즈·표정 렌더링), `f015ff1` (선택 이동·학습 연결·검수 화면)
- 다른 작업의 미커밋 변경을 보존하기 위해 별도 관리 워크트리에서 구현했다.

## 구현 범위

기존 9명의 원본 캐릭터와 장비 아트를 재사용한다. `motion/poses.ts`의 기본, 걷기 좌우, 양팔 들기, 점프, 풀이 죽기 6종 포즈를 `motion/rig.ts`가 몸통·팔·다리 레이어에 적용한다. 긴 머리와 모자는 몸통을 따라 움직이고 손 장비는 손의 회전을 따른다. 신규 래스터 그림이나 외부 이미지 서비스 의존성은 없다.

O/X 클릭으로 기존 답변 요청을 즉시 전송한다. 같은 요청에 기록된 선택을 읽어 750ms 동안 해당 위치로 이동한다. 서버의 결과가 빨리 와도 이동을 마친 뒤 반응한다. 늦으면 선택 위치에서 기다린다. 정답에는 웃는 표정과 양팔을 올린 두 번의 점프, 오답에는 허리를 약간 숙이고 팔을 내리는 자세를 보여 준다. 선택 없이 확정된 시간 초과는 가운데에서 풀이 죽은 자세를 보여 준다.

결과 복원 시 서버의 O/X 정답과 판정으로 선택 위치를 복구하고 정지된 결과 자세를 보여 준다. 같은 답변 재조회나 재시도는 동작을 다시 시작하지 않는다. 다음 문항에서는 가운데로 초기화한다. 애니메이션 이벤트가 답변·진행 API를 호출하지 않으며, 장비 로딩 실패 시 기존 정지 캐릭터로 대체한다. 첫 풀이·재도전·선택 복습에 같은 동작을 적용한다.

`prefers-reduced-motion`에서 좌우 이동 전환과 점프를 끄고 최종 감정 자세를 유지한다. 점프는 1.2초, 풀이 죽는 전환은 450ms 뒤 프레임 예약을 중지한다. 화면 이탈 시 예약과 로딩을 취소한다.

- `pnpm --dir frontend build`: TypeScript 검사 및 Vite 배포 번들 생성 통과.
- `pnpm --dir frontend lint`: 통과.
- `git diff --check`: 통과.

추가 회귀 검증은 즉시 채점·느린 채점의 순서, 양쪽 도착, 결과 복원, 선택 취소, 다음 문항 타이머 정리, 두 번의 점프 종료, 동작 줄이기 포즈를 포함한다. 학습 페이지 통합 테스트는 FIRST/REPLAY/REVIEW 각각에서 이동 시작 시 실제 요청 payload의 X 선택, 1회 전송, 버튼 잠금, 도착 후 대기, 서버 오답 수신 후 X 위치의 슬픈 자세를 확인한다. jsdom은 픽셀 백엔드가 없으므로 픽셀 모양 자체는 아래 브라우저 검수로 확인했다.

## 브라우저 검수 — 통과

개발 서버 전용 `frontend/e2e/fixtures/answer-motion.html`에서 실제 제품 컴포넌트와 캐릭터 아트를 사용했다. 기본·1번·5번 장비 × 9명 × 6개 포즈 = 162개 캔버스의 렌더링 완료를 확인했다. 외형·머리·양팔·다리와 장비의 시각 검수를 수행했다.

- O 클릭: 왼쪽을 바라보며 걷기 → O 위치 → 양팔을 올린 정답 자세.
- X 키보드 Enter: 오른쪽 이동 → 보라와 5번 장비를 착용한 오답 자세.
- X 응답 대기: `waiting`과 X 위치 유지 → 서버 정답 버튼 → 정답 반응.
- 360px 뷰포트: 캐릭터가 장면 안에 들어가고 선택 지점과 캐릭터 중심의 차이는 0px. 문서 가로 넘침 없음.
- HMR 과정의 검수 페이지 중복 root 경고를 방지하도록 해제 처리를 추가하고 새로고침 후 확인했다.

실제 운영 계정이나 운영 DB는 사용하지 않았다. 백엔드 변경이 없어 전체 HTTP E2E를 새로 실행하지 않았으며, 서버 연동은 기존 MSW 통합 경계에서 검증했다. 운영체제의 동작 줄이기 설정은 변경하지 않았고 해당 동작은 포즈 단위 테스트와 CSS 검토로 확인했다.

## 리뷰와 재현

변경·신규 파일 전체를 자체 검토했다. 독립 리뷰 도구/에이전트 리뷰는 수행하지 않았다. 답변 및 다음 문제 요청 경로를 유지하고, 문항별 키로 장면 수명을 분리하며, 프레임/타이머/AbortController 정리를 확인했다.

이 브랜치에서 `pnpm --dir frontend dev --port 8103 --strictPort` 실행 후 `/e2e/fixtures/answer-motion.html`을 열면 캐릭터·장비 선택, O 정답, X 오답, 응답 대기와 전체 포즈를 확인할 수 있다. 검수 페이지는 배포 번들에 포함되지 않는다.
