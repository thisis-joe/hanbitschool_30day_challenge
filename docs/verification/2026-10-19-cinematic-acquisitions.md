# 전체 화면 경험치·아이템 획득 연출

- 기능 브랜치: `feat/cinematic-acquisitions`
- 기준: `76406ba`; 구현 및 회귀 테스트 커밋: `df1b52f`.
- 별도 관리 워크트리에서 구현했다. 원본 `feat/responsive-ux-flow`의 진행 중인 수정은 변경하지 않았다.

## 구현

경험치 획득은 2.6초, 아이템 획득은 4.4초 동안 전체 화면에서 재생한다. 화면 암전, 큰 광선과 충격파, 64개의 파티클, 금빛 경험치 메달을 사용한다. 아이템은 닫힌 상자의 진동 → 뚜껑이 튀어 오르며 열림 → 빛기둥과 확대된 장비 등장 순서다. 장비 그림은 실제 인벤토리와 같은 EquipmentIcon이다.

전체 화면 연출이 끝나면 기존 카드의 2.4초 연출로 이어진다. 건너뛰기와 Escape로 즉시 진행할 수 있다. 모달 내 Tab/Shift+Tab 포커스를 유지하고 종료 시 보상 카드로 포커스와 화면 위치를 돌려준다. 계정·콘텐츠·획득 ID에 따른 한 번만 재생 규칙과 실제 서버 보상 값은 유지했다. 동작 줄이기 설정은 연출을 생략하고, 재생 도중 설정이 바뀌어도 즉시 종료한다.

## 검증

Node 24 / Chromium, 로컬 개발 서버 `http://127.0.0.1:8094`. 브라우저 입력과 API 응답은 기존 E2E 합성 학생·문항·보상 데이터를 사용했다. 실제 계정이나 운영 보상을 변경하지 않았다.

- 기준 회귀 테스트 8개 통과 후 새 전체 화면 → 카드 전환 테스트의 예상 실패를 확인하고 구현.
- `vitest run`: 37개 파일, 290개 테스트 통과.
- 최종 포커스 보완 후 관련 테스트 8개 재실행 통과.
- `tsc -b && vite build`: 최종 코드 빌드 통과.
- `eslint .`, `git diff --check`: 통과.
- `HANBIT_E2E_BASE_URL=http://127.0.0.1:8094 playwright test e2e/game-celebrations.spec.ts`: 최종 5개 통과.
- 1280px 자동 종료, 390px/320px 건너뛰기 및 Escape, 입력 포커스, 실제 착용 저장 1회, SPA 재방문 재생 방지, 가로 넘침 없음, 스크롤 잠금 해제, 동작 줄이기 및 재생 중 설정 변경 확인. 브라우저 오류 없음.
- 초기 브라우저 검증에서 Tab이 브라우저 외부로 이동하는 것을 발견하고 단일 건너뛰기 버튼으로 순환하도록 보완했다.

범위 검토: 새 컴포넌트·스타일·시퀀스 훅과 두 보상 컴포넌트, 단위/E2E 테스트 전체를 작성자가 검토했다. 별도 독립 리뷰는 수행하지 않았다. 변경된 시각 디자인은 데스크톱·모바일 실제 브라우저에서 확인했다.
