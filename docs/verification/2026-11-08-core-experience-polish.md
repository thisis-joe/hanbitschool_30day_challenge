# 핵심 경험 개선 검증

[설계](../superpowers/specs/2026-11-08-core-experience-polish.md) · [실행 계획](../superpowers/plans/2026-11-08-core-experience-polish.md) · [숲 도트 기준](2026-11-08-forest-pixel-art.md)

## 화면 전후

| 과제 | 개선 전 | 개선 후 |
| --- | --- | --- |
| 320×568에서 학습 시작 | 버튼의 약 44%만 첫 화면에 보였다. | 시작 버튼은 문서 y=447~499px에 표시된다. 시작과 이어풀기 모두 320×568·390×844 첫 화면 전체 노출을 검사했다. |
| 답변 후 근거 읽기 | 결과에서 XP 카드가 근거보다 먼저 나왔다. | 판정·정답과 해설이 XP보다 먼저 표시된다. 동작 줄이기 및 합성 API의 단일 측정에서 답변 응답 관찰 후 해설 노출 확인까지 16ms였다. 응답 자체의 지연이나 실기기 성능을 뜻하지 않는다. |
| 390×844에서 교사 탐색 | 학급 요약 아래 학생·문항 탭 시작 y=1,609px. | 합성 학급의 탭 시작 y=431px. 320×568에서도 미참여 학생 바로가기와 학생·문항 탐색 버튼이 보인다. |
| 교사 목록·상세 | 좁은 화면에서 상태나 비율을 보려면 표를 가로로 밀었다. 상세의 복귀 링크는 이전 조건을 보존했지만 목록 제목으로 초점이 이동했다. | 모바일에서 학생 이름·상태·미개선 수와 문항·오답률·응답 수가 함께 보인다. 명시적 목록 복귀는 검색·필터·정렬·페이지를 보존하며 원래 행이나 문항 버튼을 다시 표시하고 포커스를 복원한다. |

화면 크기와 합성 학급·응답 건수를 맞춰 비교했다. 320px 학생 홈과 답변, 390px 교사 통계에서 글자 기본 크기를 200%로 늘렸을 때 문서 가로 넘침은 0px이었다. 키보드와 동작 줄이기는 제품 화면에서 별도로 확인했다. 지정 색상 기준 명암비는 학생 본문과 읽기 바탕 11.51:1, 교사 참여 라벨과 바탕 5.45:1이었다.

## 구현과 확인 범위

- 학생 학습은 [PR #14](https://github.com/thisis-joe/hanbitschool_30day_challenge/pull/14), 숲 도트 아트는 [PR #15](https://github.com/thisis-joe/hanbitschool_30day_challenge/pull/15)로 병합했다. 도트 아트 변경 뒤 Chromium 87개와 격리 PostgreSQL의 학습·게임 검증 15개가 통과했다.
- 교사 화면은 전체 학급의 요약과 필터 적용 목록을 분리한다. 응답이 없는 경우를 0%와 구분하고 비율에 응답 분모를 표시한다. 모바일에서는 핵심 열을 먼저 보여 주고 나머지 근거는 상세에서 제공한다.
- 교사 검증에는 합성 브라우저 화면과 별도 PostgreSQL에 저장한 데이터가 사용된다. 기존 전용 테스트의 연결 정보는 임시 사본에서만 새 프로젝트·설정 경로·루프백 포트로 맞췄다. 저장소의 테스트 소유권 제한은 그대로 적용된다.
- 교사 변경 뒤 브라우저 UX 검사 36개, 검증 안전성 검사 14개, 실제 교사 시나리오 7개가 통과했다. 실제 서버에서 25명 학급의 검색·페이지, 문항 상세·타 학교 접근 차단, 서버 재시작 후 학습과 통계 기록을 확인했다.
- 서버 타이머, 콘텐츠, 저장·보상·권한은 기존 계약을 사용한다. 제한시간 조정은 학습 목적과 접근성 요구를 함께 살펴 정할 정책이다. 실물 모바일, 학생·교사 관찰, 별도 독립 검토는 이 실행의 증거에 포함되지 않는다.
