# 숲 답변 장면 도트 아트

## 기준과 적용

- 숲 공터는 192×128 정수 격자에서 수평·수직 계단형 윤곽으로 그렸다. 원경은 채도를 낮춘 청록, 앞쪽은 짙은 녹색과 흙색, 상호작용 표지는 밝은 회녹색과 노란빛을 쓴다. 겹치는 면과 수평 명암으로 깊이를 표현한다. 발을 놓는 기준은 원본의 94번째 줄이다.
- 숲 바위는 64×58 격자를 128×116 CSS px로 표시한다. O/X는 24×24 격자를 48×48로 표시한다. 둘 다 1× 화면에서 2배, 2× 화면에서 4배에 해당한다. 사실·해석과 문제·해설은 한글 폰트로 읽는다.
- 화면을 채우는 배경은 3:2 비율로 아래를 고정하고 가로 또는 세로를 잘라낸다. 가변 뷰포트에서는 배경 배율이 분수가 될 수 있다. 원본의 계단형 윤곽과 픽셀 보간 설정으로 흐림을 줄인다.
- 캐릭터는 기존 9종의 176×216 캔버스와 승인된 장비를 사용한다. 원본 얼굴·장비를 보존하기 위해 작은 휴대폰에서는 표시 배율이 분수일 수 있다. 정지 픽셀과 관절 프레임은 기존 아바타 검증과 대조한다. XP는 별도 가림막 없이 장면 안에서 밝은 교차 모양 입자를 계단식으로 움직인다. 동작 줄이기 설정을 따른다.

## 범위

새 격자는 학생의 숲 답변 장면에 적용했다. 홈·옷장·지도 배경과 마을·바닷가의 배경 및 자연물은 기존 그림을 사용한다. 다음 지역을 바꿀 때 지역별 지면 줄, 표지의 글자 영역, 기존 장비가 입혀진 정지·동작 프레임을 이 기준으로 다시 검수한다. 앞서 제작된 지면·장비·지도·캐릭터 동작 개선을 함께 통합했다.

## 확인 결과

- 단위 검사 311개, TypeScript·Vite 빌드, ESLint 통과.
- Chromium 87개 통과. 320·390·768·1280px, 장비 3개 조합을 포함한 9종 모션, 숲 1×·2× 밀도, 숲·마을·바닷가의 지면과 표지, 지도·옷장·보상·학습 동선을 포함한다.
- 격리 PostgreSQL의 학습·게임 검사 15개 통과. 기존 검사 도우미의 실행 대상은 임시 사본에서만 이 작업의 정확한 프로젝트·설정 경로·루프백 포트로 맞췄다.
- 같은 합성 보라 캐릭터와 안경으로 390px 표시를 비교했다. 바위의 한글이 데스크톱에서 돌의 밝은 면을 벗어나는 경우를 재현하고 글자 크기를 보정했다. 실제 휴대폰과 사용자 관찰은 별도다.
