# 핵심 경험 개선 실행 계획

[설계](../specs/2026-11-08-core-experience-polish.md) · 기준 `4e44453` · 순차 실행 및 main 병합

| 작업 | 실행과 검증 |
| --- | --- |
| 1. 학생 학습 | 선행 피드백·그림 중심 학습의 제품 변경을 이어받는다. 첫 화면 시작/이어풀기와 서버 대기·해설·다음 행동을 확인하고 고친다. 5문항·복습·재도전·시간 초과는 기존 격리 서버 검사로 확인한다. |
| 2. 도트 아트 | 학생 흐름 확정 후 기존 도트 표지·지면·아바타 개선을 이어받는다. 대표 숲에서 원본 격자·확대·장비·효과를 검수하고 필요한 자산과 배율을 조정한다. 실제 브라우저로 장비와 9종 캐릭터 동작을 회귀 검사한다. |
| 3. 교사 통계 | 학급의 참여와 상세 진입을 우선 배치한다. 분모·빈 표본·모바일 행의 가독성과 목록 복귀를 확인한다. 기존 권한·집계와 격리 서버 검사를 재실행한다. |

각 단계에서 관련 단위·브라우저 검사와 전체 프런트엔드 검사, 빌드, 린트를 실행하고 전후 화면과 제약을 기록한다. 검증한 커밋을 기능 브랜치에서 PR로 보내고 GitHub 검사와 병합 가능 상태를 확인한 뒤 병합 결과를 읽는다.
