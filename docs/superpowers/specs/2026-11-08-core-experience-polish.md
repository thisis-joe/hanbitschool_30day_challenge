# 한빛학교 핵심 경험 개선

목표는 학생의 하루 5문항, 대표 숲 장면의 도트 아트, 교사의 학급 통계 순으로 다듬고 각 기능을 검증해 main에 병합하는 것이다. 최초 기준은 `4e44453`이다. 로컬에 별도로 남은 학생 UI와 아트 개선은 현재 요구와 대조해 관련 구현 커밋을 이어받는다.

## 학생 학습

320×568, 390×844에서 학습 시작·이어풀기가 첫 화면에 온전히 보인다. 문제·제한시간·한 쌍의 O/X 입력을 한 장면에서 읽을 수 있다. 입력 후에는 서버 확인 상태를 보여 주고, 확정 후 결과·정답과 근거·다음 행동을 즉시 사용할 수 있다. 평상시 XP는 장면 안에서만 짧게 표현하며 최초 회차 선물은 별도 획득 순간으로 남긴다. 타이머가 계속 흐르는 동안 학습 화면을 떠날 때의 안내를 제공한다.

## 도트 아트

대표 숲 장면에서 배경·캐릭터·장비·답변 표지·효과의 격자, 색과 윤곽을 실제 화면과 확대 화면으로 대조한다. 아트에만 도트 처리를 적용하고 본문과 표에는 읽기 좋은 한글을 쓴다. 각 화면 너비와 기기 밀도에서 이미지 크기, 흐림, 글자 가림을 확인한다. 다른 배경과 기존 장비 조합에도 적용할 수 있는 규칙과 남은 자산을 기록한다.

## 교사 통계

첫 화면에 학급과 참여 현황 및 학생·문항 탐색 입구를 배치한다. 모바일에서 이름·상태 등 주요 판단과 상세 진입에 필요한 정보가 보인다. 응답 수와 분모, 첫 답변·선택 오답·시간 초과·미응답·복습 개선, 학급 전체와 필터된 범위를 구별한다. 학생·문항 상세에서 목록으로 돌아오면 검색·정렬·필터·위치가 유지된다.

## 경계와 검증

승인된 문항과 해설, 서버 타이머·판정·저장과 첫 답변, XP·해금·소유권, 교사 권한과 학생 정보 경계를 보존한다. 실제 저장은 격리 PostgreSQL과 합성 학생으로 검증한다. 정적 화면, 브라우저 조작, 실제 저장, 사용자 관찰은 별도 증거로 기록한다. 시간 조정 정책은 학습 담당자의 판단 항목으로 분리한다. 작업 범위는 기능 브랜치와 작업 단위 커밋, GitHub의 검사와 main 병합까지다.
